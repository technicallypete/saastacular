# Foundation history (historical source-project evidence)

This directory keeps the written Goal, Spec, Plan, Result and acceptance-review records for the reusable
foundation work that this repository was exported from. They are **historical evidence from the original source
project**. They are not this repository's active management state, roadmap or backlog, and they grant no
authority, approval or release to anyone adopting this repository.

## How to read it

- Each Goal lists its records in the order Goal, Spec (with any Spec addendum), accepted Plan, Result and the
  acceptance review(s). Superseded revisions, intermediate plan reviews, dispatch and cleanup receipts and
  machine binding files were not retained; their outcomes are carried by the retained Result and review.
- [PERFORMANCE.md](PERFORMANCE.md) is the source project's performance-concern register for these Goals.
- Each file starts with an editorial note. Machine paths, agent session and worktree identifiers, personal names
  and addresses, account and project identifiers and live provider bindings are replaced with `<placeholders>`.
  Live hostnames use the reserved `foundation.test` domain. Links to records that are not included were turned
  into plain text marked "(not included)".
- Incidental mentions of the source project's name, its Compose project and role names, and the design-system
  name are kept as historical fact. They are not this repository's identity.
- **Git commit and tree hashes, MR numbers and pipeline IDs in the prose identify the original source project.
  They may not resolve in this repository**, which ships no source-project Git history. Dependency integrity
  pins in the shipped code are separate and remain real.

## What these records do not claim

The source project's foundation barrier (G021) has **not** been accepted. Live provider and custom-domain
qualification (G057) remains **open and unexecuted**. Nothing here states or implies that either passed, that
the foundation is production-qualified or that it meets any compliance standard. Where a record shows a
failed, canceled, waived or unexecuted check, that outcome stands as written.

Goals that were not completed, were deferred, or are product-specific are not included (for example G021, G052,
G054, G056, G057 and G059).
